# 文档索引

> **透明桌宠（Transparent Pet）**——Unity 2022.3 重制的 Windows 桌面宠物：全屏透明置顶窗口 + 点击穿透，液态玻璃 / PBF 果冻 / 碎裂 / 贴图四条物种线，托盘常驻、拖拽抛射物理。设计参照姊妹 Godot 版（`../game/transparent-pet/`），实现全部重写。
