## P1 托盘重加图标无重试（P1 修复项的残留缺口）

- **文件**：`Assets/Scripts/Platform/NativeTray.cs`（`ReaddIcon` / `Pump`）
- **现状**：TaskbarCreated 广播到达后只 `NIM_ADD` 一次；失败仅 `Debug.LogWarning`。
- **缺口**：重加可能撞上 explorer 任务栏初始化未完成（MS 文档提示的竞态），单次失败 = 图标再次永久消失，且无第二次机会（下次 TaskbarCreated 要等 explorer 再死一次）。托盘是设置/退出唯一入口，自愈必须可靠。
- **方案**：实例加剩余重试计数（如 5 次），`ReaddIcon` 失败时递减并登记待重试；`Pump()` 每帧检查，间隔约 500ms 重试至成功或次数用尽。
- **验收**：重试计数纯逻辑可注入单测（沿用 `TrayMenuTests` 风格）；实机杀 explorer.exe 验证图标恢复。

## P2 GDI 缓存与编辑器域重载不兼容（P2 修复项的残留缺口）

- **文件**：`Assets/Scripts/Platform/NativeScreenCapture.cs`（static 缓存字段）
- **现状**：`cachedMemDc` / `cachedBmp` 进程生命周期复用；编辑器域重载会把 static 清零，而 GDI 句柄属进程 → 每次域重载泄漏一对 DC+位图，直到编辑器退出。
- **影响面**：仅编辑器（Player 构建无域重载）；但工程重度使用编辑器开发。
- **方案**：`#if UNITY_EDITOR` 注册 `AssemblyReloadEvents.beforeAssemblyReload` 释放缓存；释放前先 `SelectObject` 还原默认位图（选中态位图 `DeleteObject` 会失败，见缓存字段注释）。
- **验收**：编辑器内改脚本触发多次域重载，任务管理器 GDI 对象列不增长。
